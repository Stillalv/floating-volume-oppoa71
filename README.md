# Floating Volume Button untuk Oppo A71 (Android 7.1)

Aplikasi pengganti tombol fisik volume HP yang rusak. Memunculkan widget melayang (*floating bubble*) di layar yang bisa digeser dan ditekan sekali untuk mengatur volume musik / panggilan / alarm.

## Fitur
1. **Single Tap (Sekali Tekan):** Langsung memunculkan bilah slider volume bawaan sistem Android di layar.
2. **Expandable Mini Menu:** Tersedia tombol cepat Volume Up (+), Volume Down (-), dan tombol slider penuh.
3. **Draggable Bubble:** Lingkaran melayang bisa digeser ke posisi mana saja di tepi layar.
4. **Ringan & Hemat Baterai:** Dibuat khusus dengan Native Android tanpa framework berat, ukuran APK < 3 MB.
5. **Dukungan Oppo A71 / ColorOS:** Menggunakan mode kompatibilitas overlay Android 7.1 Nougat.

## Cara Mendapatkan APK Tanpa Install Android Studio di Laptop:
1. Buat repository baru di [GitHub.com](https://github.com) (Gratis).
2. Upload semua file dalam folder ini ke repository GitHub Anda.
3. Buka tab **Actions** di repository GitHub Anda.
4. GitHub akan meng-compile aplikasi secara otomatis dalam ~1 menit.
5. Unduh file `.apk` dari bagian **Artifacts**, lalu install langsung di HP Oppo A71 Anda.
